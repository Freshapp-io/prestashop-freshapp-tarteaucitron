    En bref

    Une bannière de consentement, sans intégration manuelle

    Depuis le RGPD et la directive ePrivacy, aucun cookie non essentiel — mesure d'audience, réseaux sociaux, vidéos embarquées — ne peut être déposé avant le consentement explicite du visiteur. tarteaucitron.io est un moteur open-source éprouvé pour ce rôle, mais son installation correcte dans un thème PrestaShop et son maintien à jour restent des points de friction. Ce module gère l'intégration à votre place : un écran de configuration, deux modes de chargement, un point d'entrée pour vos services additionnels.

    • Intégration du script tarteaucitron.io en un seul écran de configuration
    • Mode CDN direct ou mode cache local avec re-téléchargement automatique
    • Détection automatique du domaine de la boutique, ou domaines multiples renseignés à la main
    • Champ dédié pour déclarer des services additionnels (JS) sans toucher au thème
    • Bascule pour afficher ou masquer l'entrée de menu back-office

    Pour commencer

    Installation

    1. Installer le module

      Dans le back-office, ouvrez Modules → Gestionnaire de modules, cliquez sur Téléverser un module, puis glissez-y le fichier .zip que vous avez téléchargé ou acheté. L'installation se lance automatiquement.

    2. Ouvrir l'outil

      Une fois installé, ouvrez-le via le bouton Configurer de la liste des modules, ou depuis son entrée de menu Préférences → Tarteaucitron dans le back-office (affichable ou masquable depuis l'écran lui-même).

    3. Coller le tag d'installation

      Créez un compte gratuit sur tarteaucitron.io. Votre compte fournit un tag d'installation de cette forme :

      <script src="https://cdntag.tarteaucitron.io/load.js?domain=votre-boutique.fr&uuid=VOTRE_UUID"></script>

      Collez ce tag complet dans le champ Tag d'installation tarteaucitron.io, puis enregistrez : le module en extrait l'identifiant, c'est-à-dire la valeur qui suit uuid=, et le reporte dans le champ Identifiant d'API. Si le domaine du tag diffère de celui de la boutique, il est aussi reporté dans Domaine(s). Vous pouvez également saisir l'identifiant à la main.

      Laissez Domaine(s) vide pour que le module utilise le domaine de la boutique, ou renseignez-le si vous exploitez plusieurs environnements (production, recette…).

    Principe

    Comment ça marche

    Le module s'accroche à deux hooks front-office pour placer le script tarteaucitron le plus tôt possible dans la page — une exigence de tarteaucitron.io lui-même, car un chargement tardif laisse le temps aux iframes tierces (YouTube, Vimeo…) de s'exécuter avant que le consentement ne soit demandé :

    1. Préconnexion

      Dès l'en-tête de la page, des indices dns-prefetch et preconnect sont ajoutés vers le CDN tarteaucitron.io, pour gagner du temps sur la connexion.

    2. Chargement du loader

      Le script load.js — servi depuis le cache local ou depuis le CDN selon le mode choisi — est injecté en tout début de <head>, avant tout autre script de la page.

    3. Services additionnels

      Si un code JS personnalisé est renseigné, il est injecté juste après le loader, pour garantir qu'il s'exécute une fois tarteaucitron déjà chargé.

    Au quotidien

    Déclarer des services additionnels

    tarteaucitron.io détecte automatiquement une partie des services tiers courants. Pour les autres, le champ Add services (JS Code) accueille le code JavaScript de déclaration fourni par la documentation tarteaucitron.io (étape « Add services » de leur guide d'installation libre).     Performance

    Mode CDN ou cache local

    Mode CDN

    Comportement par défaut : load.js est chargé en direct depuis cdntag.tarteaucitron.io à chaque visite.

    Mode cache local

    Le module télécharge load.js une fois, le sert avec les assets du site, puis le renouvelle automatiquement selon une durée de cache (en jours) que vous définissez.

    L'écran de configuration affiche en permanence le statut du cache (Mode CDN, Cache actif, Cache expiré, Non téléchargé, Cache invalide, UUID modifié…) ainsi qu'un bouton pour forcer un re-téléchargement immédiat. Si le téléchargement échoue ou si la licence tarteaucitron.io ne couvre pas le domaine, le module repasse automatiquement sur le CDN plutôt que de servir un cache invalide.

    Un outil d'intégration, pas un avis juridique. Ce module s'assure que la bannière tarteaucitron.io se charge avant tout autre script du site ; la configuration des services déclarés et le paramétrage de votre compte tarteaucitron.io restent de votre responsabilité.

    On this page

      Overview

      A consent banner, without the manual integration

      Under GDPR and the ePrivacy directive, no non-essential cookie — analytics, social widgets, embedded video — may be set before the visitor gives explicit consent. tarteaucitron.io is a proven open-source engine for that job, but wiring it correctly into a PrestaShop theme, and keeping it current, remains fiddly. This module handles that integration for you: one settings screen, two loading modes, one place to declare extra services.

      • Tarteaucitron.io integration from a single settings screen
      • Direct CDN mode or local cache mode with automatic refresh
      • Automatic shop-domain detection, or multiple domains entered by hand
      • Dedicated field for declaring additional services (JS) without touching the theme
      • Toggle to show or hide the back-office menu entry

      Getting started

      Installation

      1. Install the module

        In the back office, open Modules → Module Manager, click Upload a module, then drag in the .zip file you downloaded or bought. Installation starts automatically.

      2. Open the tool

        Once installed, open it via the Configure button in the module list, or from its menu entry Preferences → Tarteaucitron in the back office (can be shown or hidden from that same screen).

      3. Paste the installation tag

        Create a free account on tarteaucitron.io. Your account provides an installation tag like this one:

        <script src="https://cdntag.tarteaucitron.io/load.js?domain=your-shop.com&uuid=YOUR_UUID"></script>

        Paste the whole tag into the tarteaucitron.io installation tag field and save: the module extracts the identifier, i.e. the value after uuid=, and copies it into the API ID field. If the tag's domain differs from the shop's, it is copied into Domain(s) as well. You can also type the identifier by hand.

        Leave Domain(s) empty to let the module use the shop's domain, or fill it in if you run several environments (production, staging…).

      Principle

      How it works

      The module hooks into two front-office events to place the tarteaucitron script as early as possible in the page — a requirement from tarteaucitron.io itself, since a late load gives third-party iframes (YouTube, Vimeo…) time to run before consent is even asked:

      1. Preconnect

        From the page header onward, dns-prefetch and preconnect hints point to the tarteaucitron.io CDN, saving connection-setup time.

      2. Loading the loader

        The load.js script — served from local cache or from the CDN depending on the mode — is injected at the very start of <head>, ahead of every other script.

      3. Additional services

        If a custom JS code is set, it is injected right after the loader, guaranteeing it runs once tarteaucitron is already loaded.

      Day to day

      Declaring additional services

      tarteaucitron.io automatically detects many common third-party services. For the rest, the Add services (JS Code) field accepts the JavaScript declaration code from tarteaucitron.io's own documentation (the "Add services" step of their free-installation guide). The module writes it to a dedicated static file, shipped as a regular front asset — no theme edits required, and the file is removed automatically when the field is cleared.

      Performance

      CDN mode or local cache

      CDN mode

      Default behaviour: load.js is loaded live from cdntag.tarteaucitron.io on every visit.

      Local cache mode

      The module downloads load.js once, serves it alongside the site's own assets, then refreshes it automatically after a cache duration (in days) that you set.

      The settings screen always shows the cache status (CDN mode, Cache active, Cache expired, Not downloaded, Invalid cache, UUID changed…) plus a button to force an immediate re-download. If the download fails, or the tarteaucitron.io licence does not cover the domain, the module falls back to the CDN automatically rather than serving an invalid cache.

      An integration tool, not legal advice. This module makes sure the tarteaucitron.io banner loads ahead of every other script on the site; configuring the declared services and your tarteaucitron.io account remain your responsibility.
